# Python Lecture

Interactive Python lecture site — lessons, a live in-browser Python playground (Pyodide) and quiz games.
Same stack as NGCP `employee-frontend`: Vue 3 + TypeScript + Vite, Ant Design Vue, Pinia, Vue Router,
vue-i18n, VueUse, unplugin auto-import / components / icons, SCSS, ESLint + oxlint + Prettier, Vitest.

```sh
npm install
npm run dev         # http://localhost:3100
npm run test:unit
npm run build
```

## Tracks

- **Python Foundations** — Day 1 (print, variables, types, input).
- **Python for Data Science** — DS 1–7: collections, loops & functions, NumPy, pandas, cleaning & groupby,
  matplotlib, and a full café-sales analysis project.

NumPy, pandas and matplotlib load on demand in the browser (Pyodide) the first time a code block imports
them; matplotlib charts are captured and shown under the output. The CSV datasets in
`src/data/datasets/` are generated by `python3 scripts/generate_datasets.py` and written into the
in-browser Python working directory, so lessons can call `pd.read_csv("cafe_sales.csv")`.

## Adding content

- **A lesson**: add a `*.lesson.ts` file (typed by `Lesson` in `src/models/lesson.model.ts`, with a `track`)
  and register it in `src/data/lessons/index.ts`. Write Python with the `py` template tag (flush-left). Blocks: `text`, `code`, `analogy`, `table`, `callout`, `quiz`.
- **A game**: add a question bank in `src/data/games/` (typed by `GameDefinition`) and register it in
  `src/data/games/index.ts`. Every game uses the shared `QuizGame` engine (timer, streaks, scoring, best score).
